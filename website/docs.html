Getting started

cartography is a Tessel library for maps. Add it to a project:

tessel add cartography

It brings in geodesy (coordinate systems) and viewport (panning and zooming). To call them yourself, as in geodesy.epsg(32651), add them to your project too and import them:

import cartography
import geodesy     // only to name coordinate systems yourself
import viewport    // only to draw on a Canvas of your own

Everything is under the cartography. prefix. A program usually goes like this:

  1. Make a Map, in Web Mercator unless you give it another crs.
  2. Add layers: a basemap (openStreetMap()), layers read from files (readLayers, readRaster), or layers made in code.
  3. Give layers a style and labels.
  4. Show it in a MapView, draw it on your own Canvas, or save it as a picture with savePicture or renderImage.
import cartography

fn startingMap() -> cartography.Map {
    var m = cartography.Map()
    m.add(cartography.openStreetMap())
    if let layers = cartography.readLayers("parcels.gpkg").value() {
        for layer in layers {
            m.add(layer)          // reprojected into the map's system
        }
    }
    m
}

app Parcels(title: "Parcels", width: 900, height: 600) {
    state m = startingMap()
    cartography.MapView(map: m, legend: true)
}

A Map and its layers are plain values. Change a layer through m.layers[i] and call m.refresh(i) afterwards, so the map works out its classes, labels and drawing again.

There are worked programs for every part of the library on the examples page.

MapView

public view MapView(map: bind Map, scaleBar: Bool = true, zoomButtons: Bool = true, northArrow: Bool = false,
                    legend: Bool = false, imperial: Bool = false, selects: Bool = true, keys: Bool = false,
                    onMouse: fn(Float, Float) = { lon, lat in }, onClick: fn(Hit?) = { hit in })

A ready-made map for an app, bound to a Map in the app's state. A drag pans; the wheel or a pinch zooms about the mouse; a double click fits the map; Shift and a drag zooms into a box. Tiles download as the view moves.

  • scaleBar, zoomButtons (+, − and ⤢), northArrow, legend: what's drawn over the map.
  • imperial: the scale bar in feet and miles.
  • selects: a clicked feature is also selected, and others cleared.
  • keys: arrows pan, + and − zoom, 0 shows everything. It takes the window's keys while the map shows, so it's off unless asked.
  • onMouse: gets the longitude and latitude under the mouse as it moves.
  • onClick (the trailing block): gets the top feature under a click, or nil.
state m = startingMap()
state picked = ""
state place = ""

cartography.MapView(map: m, northArrow: true, legend: true, onMouse: { lon, lat in
    place = "{lat.formatted(decimals: 4)}, {lon.formatted(decimals: 4)}"
}) { hit in
    if let h = hit {
        picked = m.attributes(h).map { p in "{p.0}: {p.1}" }.joined(separator: ", ")
    }
}

Your own Canvas

To draw a map in a Canvas of your own instead of MapView:

  1. Call m.vp.resize(w, h) from .onResize.
  2. Pass pointer events to m.vp.handle(e); it returns whether the view changed.
  3. Call m.draw(g), then drawLegend, drawMapScaleBar and drawNorthArrow where you want them.
  4. For basemaps, call fetchTiles after every change of view, and keep the files it starts in m.loading.
  5. With vp.smooth on, call m.vp.tick() from a timer (every(seconds:)) so moves animate; or set m.vp.smooth = false.
Canvas { g in
    let _r = redraw                 // draw again when a tile comes in
    m.draw(g)
    cartography.drawMapScaleBar(g, m, x: 14, y: g.height - 22)
}
.onResize { w, h in
    m.vp.resize(w, h)
    fetch()
}
.onPointer { e in
    if m.vp.handle(e) {
        fetch()
    }
}

fn fetch() {
    let started = cartography.fetchTiles(m, arrived: { path, ok in
        m.loading.remove(path)
        redraw += 1
    }) { paths in
        if cartography.warpTileLayers(m) {   // only maps not in Web Mercator
            redraw += 1
        }
    }
    for path in started {
        m.loading.insert(path)
    }
}

Layers

A Layer is a vector layer (features with shapes and attributes), a tile layer (a basemap) or a raster layer, as kind says. A vector layer has one Geometry in geoms and one value in each of its columns for each feature.

var towns = cartography.Layer(name: "Towns", geomKind: .point)
towns.geoms = [cartography.pointGeometry(121.0, 14.6), cartography.pointGeometry(120.6, 16.4)]
towns.columns = [
    cartography.textColumn(name: "name", values: ["Manila", "Baguio"]),
    cartography.numberColumn(name: "people", values: [1846513, 366358], whole: true),
]
m.add(towns)

Symbols and styles

A layer's style is a single symbol for every feature, a class for each value of a field (categorized), or classes of a number field's values (graduated). After changing a style on a map, call m.refresh(i).

var roads = layers[0]
roads.style.symbol = cartography.Symbol(stroke: cartography.rgb(200, 40, 40), strokeWidth: 3, casing: true)

var parcels = layers[1]
parcels.style = cartography.categorizedStyle(layer: parcels, field: "landuse")

var countries = layers[2]
countries.style = cartography.graduatedStyle(layer: countries, field: "POP_EST",
    mode: .naturalBreaks, count: 5, ramp: "YlOrRd")
countries.style.classes[0].label = "Fewest"

Reading and writing files

readLayers and writeLayer go by the file's extension. Readers give a Result whose error says what's wrong; writers give Error? (nil when it worked).

match cartography.readLayers("lots.shp") {
    .failure(e) -> print(e.message)
    .ok(layers) -> {
        if let e = cartography.writeLayer(layers[0], "lots.geojson") {
            print(e.message)
        }
    }
}

// Or, when a failure needs no message:
if let layers = cartography.readLayers("roads.gpkg").value() { … }

Layers keep their file's coordinate system (from a .prj, a GeoPackage's srs_id, GeoTIFF keys, or WGS 84 for GeoJSON, KML and GPX). Map.add reprojects them. A file with shapes of several kinds gives one layer for each kind.

public fn readLayers(_ path: String) -> Result<[Layer]>
Reads a file of map data: GeoJSON (.geojson, .json), a shapefile (.shp, or the .dbf, .shx or .prj beside it), delimited text (.csv, .tsv, .txt), KML, GPX, a GeoPackage, a .wkt file with a geometry on each line, or a raster (see readRaster). Layers are named after the file, with source set to its path. 
public fn writeLayer(_ layer: Layer, _ path: String) -> Error?
Writes a vector layer: .geojson/.json (WGS 84), .shp (with its .shx, .dbf, .prj and .cpg), .gpkg, .csv, .kml (WGS 84), .gpx (WGS 84; not polygons) or .wkt. A file that's there is replaced. 
public fn readableExtensions() -> [String]
The extensions readLayers reads (lower case, no dot). 
public fn writableExtensions() -> [String]
The extensions writeLayer writes.

Rasters

A raster layer has kind == .raster, a Raster of values and a RasterStyle saying how it looks. A raster in another system is warped into the map's.

if let read = cartography.readRaster("dem.tif").value() {
    var dem = read
    dem.rasterStyle = cartography.rampRasterStyle(dem, ramp: "Terrain")
    dem.rasterStyle.classes = 10        // ten steps instead of a smooth ramp
    dem.opacity = 0.75
    m.add(cartography.hillshade(dem))
    m.add(dem)
}

Basemap tiles

A tile layer has kind == .tiles and a urlTemplate. In a map not in Web Mercator its tiles are warped to fit. Each source carries its attribution, which the map shows in the corner.

Tiles download a few at a time with a User-Agent, are kept on disk (Map.tileFolder), and are asked for again after a week. OpenStreetMap's servers are for light use; a busy app should use its own tile server or a paid service.

m.add(cartography.openStreetMap())
if let s = cartography.tileSource(named: "Esri World Imagery") {
    m.add(cartography.tileLayer(s))
}
m.add(cartography.xyzLayer(url: "https://tiles.example.com/{z}/{x}/{y}.png", name: "Ours",
    attribution: "© Us", maxZoom: 18))
m.add(cartography.wmsLayer(service: "https://example.com/geoserver/wms", layers: "roads,rivers"))

public fn tileSources() -> [TileSource]

Coordinate systems

Systems are geodesy.Crs values: anything geodesy knows, from an EPSG code, a PROJ string or WKT.

let utm = geodesy.epsg(32651) ?? cartography.webMercator()     // UTM zone 51N
let lcc = geodesy.crs("+proj=lcc +lat_1=14 +lat_2=16 +lon_0=121 +datum=WGS84")
var m = cartography.Map(crs: utm)
m.setCrs(cartography.lonLat())                                  // later, in degrees
